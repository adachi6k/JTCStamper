# 作成画面の直近履歴（2026-09-24）

作成タブの下部に現在の保存先の直近3件を表示します。並びは検証済み生成記録の新しい順で、ユーザー指定の印面日付には左右されません。生成・コピー後、注釈追記後、保存先変更時に更新します。

各行に実生成日時、氏名・表示日付・下段文字、コピー記録の有無を表示します。行を選ぶと対応イベントを履歴タブで選択し、詳細・注釈を確認できます。「すべての履歴を見る」は履歴タブを開きます。コピーの記録は貼付完了を意味しないことを常時表示します。

空の履歴と読み込みエラーは別表示にし、検証失敗時は以前の一覧を消してコピー操作を無効化します。既存の記録・鍵・印面設定は変更しません。

UIは.NET 10 WPFの標準コントロールです。外部のUIツールキットやテーマは未導入。次の全体改修候補は、左側に「作成・照合・履歴」を置くサイドバー、右側に各画面、上部にファイル操作・ヘルプのメニュー、下部に保存先と操作結果を表示する構成です。「編集」メニューは実際の編集コマンドを用意するときに設け、空のメニューは作りません。今回の変更は直近履歴の追加までで、タブ構成は維持しています。

## 検証範囲

Windows x64向け通常版・軽量版のReleaseビルドとXAMLコンパイル、単一EXE内の現行アセンブリ・ランタイム・アイコンの整合を確認しました。Windowsでの起動・表示・クリック操作はこの環境では未確認です。

ネットワーク制限により保存済みNuGetパッケージだけでビルドします。単一ファイルアナライザー用ILLinkパッケージがローカルにないため、今回のビルドコマンドではEnableSingleFileAnalyzer=false、NuGetAudit=falseを指定しています。製品プロファイルへの恒久的な無効化は行っていません。トリミングは従来どおり使用しません。
