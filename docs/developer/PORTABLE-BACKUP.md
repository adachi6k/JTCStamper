# 移行用バックアップの暗号方式・形式

開発者向け資料です。PC移行の操作手順は[利用者向けガイド](../user/BACKUP.md#別pcへの移行)を参照してください。

`.jtcportable`は同じWindowsユーザー用の`.jtcbackup`とは別の形式です。復号に元PCのDPAPIは使いません。元のHMAC鍵と署名済み履歴を復元し、移行先のDPAPI CurrentUserで鍵を再保護します。生成ID・実生成時刻・表示日付・保存PNG・注釈・原本認証を引き継ぎます。現在の保存先や既存フォルダーは上書きしません。印面設定・外観設定・未追記注釈は含めません。

## 形式 v1

- マジック: ASCII `JTC-PORTABLE-1` + LF。
- ヘッダー: マジック、反復回数（32-bit big endian）、ランダムsalt 16 bytes、ランダムnonce 12 bytes、暗号文長（32-bit big endian）。
- 鍵導出: PBKDF2-HMAC-SHA256、600,000回、出力32 bytes。パスフレーズは正規化・trimせず厳密なUTF-8へ変換。12 Unicode scalar値以上、UTF-16で1024コード単位以内。無効Unicodeを拒否。
- 暗号: AES-256-GCM、タグ16 bytes。ヘッダー全体を追加認証データとして認証。保存ごとにsalt/nonceを暗号学的乱数で再生成。
- ファイル順: ヘッダー、暗号文、認証タグ。平文はVersion=1、32-byte HMAC鍵、SignedEntry配列のJSON。画像・注釈は署名済み履歴内。
- 上限: 平文256 MiB。読込ではファイル長・指定長・固定反復回数を割当/鍵導出の前に検査。不明バージョン、末尾の追加、欠損を拒否。将来の方式変更は別バージョンとし、黙って弱い設定にしない。

組込み.NET暗号APIを使用し、独自の暗号プリミティブは実装しません。[OWASPのPBKDF2推奨回数](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)を参照して固定しています。これはパスフレーズの推測を不可能にする保証ではありません。[AES-GCMのnonce再利用禁止とAAD](https://learn.microsoft.com/en-us/dotnet/api/system.security.cryptography.aesgcm.encrypt?view=net-10.0)に従います。外部の暗号監査を受けたという意味ではありません。

## 保存・復元の安全性

保存時に履歴連鎖・画像ハッシュ・読み直した鍵との一致を確認します。新しい暗号文は同じフォルダーの一時ファイルへ書込・フラッシュ後に置換し、失敗時は既存バックアップを残します。平文や未保護の鍵を一時ファイルへ書き出しません。

復元ではGCM認証を通した後、新しい一時フォルダーで履歴HMAC連鎖・順序・画像ハッシュを検証し、対象ユーザーのDPAPIで鍵を保存してからフォルダーを確定します。誤パスフレーズ/破損の区別はせず失敗表示にします。既存フォルダーへの結合・上書きはしません。復元過程の履歴は通常の製品ログ同様に暗号化されていません。復元先のWindowsファイル権限・ディスク保護も必要です。

パスフレーズと導出鍵はログへ出しません。管理可能なバイト配列は使用後にゼロ化しますが、.NET文字列やJSON内部コピー・OSのページファイルまで完全消去する保証はありません。入力欄は読み取り後・取消時に消去します。バックアップのサイズ上限はメモリ使用量の上限ではありません。大量履歴では複数のメモリコピーを要します。

HMAC鍵を持つ本人による履歴の再署名、正規の古いバックアップへの巻戻し、末尾の削除を完全に検知するものではありません。第三者向けの真正性証明ではありません。

## 再現可能な試験

Core: 同じ入力でも暗号文が異なること、鍵・履歴・注釈の往復、ヘッダー/暗号文/タグの改変、欠損/余分な末尾、誤パスフレーズ、異なる鍵で署名された履歴、既存フォルダー保全。

Windows: 実DPAPI再保護、鍵ファイルすり替え時の保存拒否、他プロセスとの共有制約による上書き失敗、実NTFS容量不足時の既存ファイル保全と容量回復後の復元。

CIのmigration-export（Windows Server 2025）とmigration-import（Windows Server 2022）は別ジョブです。元と先のマシン名/SIDのハッシュが異なることを必須とし、3印影・12記録・3注釈・画像ハッシュ・原本認証を比較します。テストデータは「CI TEST / TRANSFER」の合成印影のみです。CIで使うパスフレーズは公開の実行識別子から導出する試験専用値で、秘密保管や実ユーザーのバックアップとしての保護を目的としません。

ジョブ間で転送するのは合成暗号化ファイルと比較用ハッシュのみ（保存1日）。生の鍵・DPAPIファイル・元履歴フォルダー・実ユーザーデータは成果物へ含めません。報告にOS、ソース版、件数、成功/失敗のみを記録します。Windows 11の全環境やクラウド同期競合をこの試験だけで保証するものではありません。最終成功結果はリリースごとの受入記録に記載します。
