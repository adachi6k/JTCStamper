# ドキュメント案内

アプリを使い始める方は[トップのREADME](../README.md)、開発に参加する方は[開発者ガイド](../CONTRIBUTING.md)からお読みください。

| フォルダー | 内容 | 主な入口 |
|---|---|---|
| `user/` | 現行版の利用者向け操作ガイド | [起動・更新](user/DISTRIBUTION.md)、[バックアップ](user/BACKUP.md)、[照合](user/VERIFICATION.md) |
| `developer/` | ビルド、現行の設計・データ形式、試験手順 | [ビルド](developer/BUILD-RELEASE.md)、[設計](developer/DESIGN.md) |
| `releases/` | 各版のリリース記録、受入試験と公開確認 | [0.2.0](releases/RELEASE-0.2.0.md)、[0.2.1](releases/RELEASE-0.2.1.md)、[1.0.0 MSIX受入](releases/ACCEPTANCE-MSIX-1.0.0-2026-11-10.md) |
| `research/` | 採用案・不採用案を含む実験と意思決定の記録 | [研究記録の案内](research/README.md) |
| `archive/0.1.0/` | 旧版の仕様、受入試験、当時の結果JSON | [旧版資料の案内](archive/0.1.0/README.md) |
| `images/` | READMEなどに掲載する画面画像 | [取得元](images/README.md) |

現行仕様と過去の検討は区別します。実験結果や旧版の評価結果を、現行版の保証として扱いません。`archive/`には過去の試験資料を保存しています。
