# 照合（完全一致の初期実装）

「照合 → 原本・PNGを照合」からファイル、またはクリップボードのPNGを選びます。照合先は現在開いている履歴の保存先です。一致した候補を選ぶと生成履歴へ移動でき、注釈を確認できます。照合は履歴に書き込みません。

- `.jtc`：現在の鍵でHMACを検証し、イベントIDと署名対象の内容がローカル生成記録に一致するか確認します。
- PNG：生成記録のSHA-256とファイル全体のSHA-256を比較します。同じ印面を複数回生成した場合は全候補を表示し、1件に決めつけません。
- 結果は「一致する生成履歴あり」「一致記録なし」「判定不能」です。履歴の検証失敗、別の鍵、原本の破損、読取失敗は判定不能です。

PNGの再保存・メタデータ変更だけでも完全一致しなくなります。縮小、JPEG化、回転、切り抜き、Office経由の画像やビットマップのみのクリップボードには対応していません。これらの「一致記録なし」は完全一致記録がないという限定的な意味であり、偽造の判定ではありません。正規画像の無断コピーを区別する機能でもありません。

幾何コードによる候補探索、任意画像の印影探索、復号率と模倣画像の誤受入率の評価は今後の実装です。今回の完全一致照合を、その評価の代わりには扱いません。

既存履歴・原本の形式変更や鍵の再生成は不要です。入力上限は原本1 MiB、PNG32 MiBです。
