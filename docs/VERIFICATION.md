# 画像からの印影照合

［照合 → 画像・原本を照合］でPNG・JPEG・BMP・単一ページTIFF、原本（.jtc）を選択できます。クリップボードのPNGとBitmapにも対応します。照合先は［履歴］で選択中の保存先です。候補を選択して履歴を開けば注釈を確認できます。照合で履歴を書き換えません。

## 画像内の印影を探す

ファイル全体が生成PNGと完全一致しなければ、赤い画素から円形印を検出します。画像に複数の印影がある場合は領域の一覧から選びます。青枠で比較範囲を表示します。自動検出できない場合は画像上で印影をドラッグして囲んでください。円の外周を含め、他の赤文字を入れずに指定してください。

履歴の氏名・表示日付・下段文字を現在のレンダラーで描画し、そのPNGのSHA-256が生成時の記録と一致することを確認してから比較用画像にします。フォントや過去レンダラーの違いで再現できない記録は除外し、件数を画面に表示します。履歴のHMAC検証に失敗した場合は候補を表示しません。

赤い印影を96×96に正規化し、±8度を1度刻みで比較します。共通の円枠を除いた内部の線・文字の対称的な近傍一致度を使います。0.72以上の上位8印面に対応する履歴を提示します。同じ印面を繰り返し生成した場合は複数の履歴が出ます。類似度は確率ではありません。閾値は暫定値で、実画像の精度評価に基づくものではありません。

## 結果の意味

- 原本：認証情報・イベントID・署名対象の内容がローカル記録と一致すれば「一致する生成履歴あり」。認証できても履歴になければ「一致記録なし」。認証失敗や読み取り失敗は「判定不能」。
- PNGのファイル全体が完全一致：一致する全履歴を提示します。
- 加工された画像・文書内から抽出した印影：**「判定不能（画像の類似候補を検索）」**として候補を提示します。候補がない場合も真正／偽造を断定しません。

旧バージョンの印影には幾何コードがありません。新規生成では2-bitの区切り線コードを保存し、画像から読めれば候補を絞ります。読取値・角度差を表示し、コードによる絞り込みは解除できます。コードなしの旧履歴は残します。似た画像からイベントIDを復元できたと扱うことはできません。本物の印影の無断コピーを区別する機能ではなく、候補が見つからないことだけで偽造とも断定できません。

## 制限・検証

入力上限は画像32 MiB・1200万画素、原本1 MiB。探索用画像は長辺2048px以下に縮小します。自動検出の最小径は縮小後28pxで、赤色・ほぼ円形・円周が十分に見えるものが対象です。白黒、強い傾斜、欠け、他の赤線と重なる印影、極小画像は自動検出に失敗し得ます。手動範囲指定でも情報を復元することはできません。PDFそのものと複数ページTIFFは対象外です。

比較は直近300種類の印面、領域表示は先頭30件まで。対象外の件数・制限は画面に表示します。
