# 画像から生成履歴を探す

JTC Stamper 0.2.0の画像照合は、自分のPCに保存した履歴を探すための試験機能です。

## 照合する

1. サイドバーの［印影を照合］を開きます。
2. 画像ファイルを選ぶか、クリップボードの画像を読み込みます。
3. 複数の印影が見つかった場合は、矢印で対象を切り替えます。見つからない場合は画像上で円の外周を含めて囲みます。
4. 点数が高い履歴候補を確認し、必要なら次の候補へ切り替えます。
5. 候補の履歴を開き、上段文字・日付・下段文字に加えて、実際の生成日時や用途・注釈を確認します。

照合先は現在選択している履歴保存先です。記録があるはずなのに見つからない場合は、［履歴］メニューで保存先を確認してください。照合では履歴を書き換えません。

## 結果の読み方

| 表示 | 意味・確認すること |
|---|---|
| 一致する生成履歴あり | 保存PNGや原本と一致する記録が見つかりました。画像のコピーも一致します。 |
| 対応する生成履歴候補あり | 画像内のコードと形が合う候補です。用途や生成日時を確認してください。 |
| 形が似た履歴候補あり | 形を手がかりにした候補です。コードが一致しているとは限りません。 |
| 今回の検索では履歴候補なし | 保存先・検索条件・文字と日付を確認してください。偽造という意味ではありません。 |
| 照合の手がかりが不足しています | 縮小・圧縮などで読み取れない場合があります。元画像や切り出し範囲を確認してください。 |

**1.000は候補との比較点数で、本物である確率ではありません。保存画像のコピーは見分けられません。**

## 読み取れないとき

- PDFそのものではなく、元のPNGや、印影を十分な大きさで取り出した画像を使います。
- 円全体が入るように範囲を選び、近くの赤文字・図形をできるだけ除きます。
- 検索条件を狭めすぎていないか、保存先が正しいかを確認します。
- 0.1.0の12bit印影は0.2.0の対象外です。旧版で参照してください。

対応入力はPNG・JPEG・BMP・単一ページTIFF、原本（.jtc）、クリップボードのPNG／Bitmapです。画像は32MiB・1200万画素以内、原本は1MiB以内です。PDFや複数ページTIFFには対応していません。

比較対象は直近300種類の印面、検出領域は先頭30件、候補は上位8印面です。除外・省略された件数は画面に表示します。白黒化、強い傾き、欠け、他の赤い線との重なり、極小画像では照合できない場合があります。

点数の計算や読み取り方式を調べたい開発者は[照合の技術資料](../developer/VERIFICATION-TECHNICAL.md)を参照してください。
