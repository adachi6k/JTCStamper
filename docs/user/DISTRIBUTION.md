# ダウンロード・起動・更新

JTC Stamper 0.2.1を使う方向けのガイドです。ソースからのビルドは[開発者ガイド](../../CONTRIBUTING.md)を参照してください。

## どちらをダウンロードするか

[GitHub Releases](https://github.com/adachi6k/JTCStamper/releases)のAssetsからZIPを選びます。

通常版のSetup EXEが公開されている場合は、ZIPの代わりにユーザー別インストーラーを利用できます。管理者権限は不要です。ショートカットから起動でき、既定では `%LOCALAPPDATA%\Programs\JTCStamper` に配置します。更新時はアプリを閉じてから新版Setup EXEを実行してください。ZIP版と同じ保存先を共有しないでください。アンインストールしても履歴の `journal` と鍵の `key.dpapi` は残るため、削除する前にバックアップを作成してください。Setup EXE自体は未署名で、Windowsの警告が出る場合があります。

| 版 | おすすめする方 | 必要な環境 |
|---|---|---|
| Standard（通常版） | 初めて使う方、迷った方 | Windows 11 x64。必要な.NETを同梱 |
| Lite（軽量版） | 必要な.NETがすでに入っている方 | Windows 11 x64、.NET 10 Desktop Runtime x64 |

両版の機能は同じです。Windows 10・ARM64は対応対象外です。

## 起動する

1. ZIPをダウンロードし、専用フォルダーへすべて展開します。例：`C:\Apps\JTCStamper`。
2. `JTCStamper.App.exe`をダブルクリックします。管理者権限やインストーラーは不要です。
3. 履歴の準備が終わったら、文字と日付を確認して［生成してPNGコピー］を押します。

ZIPの中から直接起動せず、書き込み可能なローカルフォルダーを使ってください。260文字を超える長いEXEパスは対応対象外です。通常版は一時フォルダーにも空き容量と書き込み権限が必要です。

Liteで.NETの導入を求められた場合は、[Microsoftのダウンロードページ](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)から **.NET Desktop Runtime / Windows x64** を導入するか、Standard版を使ってください。開発用のSDKは不要です。

0.2.1のEXEは自己署名のため、Windowsが信頼する発行元として認識されず、SmartScreenなどの警告が出る場合があります。組織のPCで起動を禁止されている場合は管理者に確認してください。

## 0.2.0から0.2.1への更新

印影・履歴の形式は変わりません。更新前にバックアップし、アプリを終了してください。同じインストーラー版から更新する場合は新版Setup EXEを実行します。0.2.0のZIP版からインストーラー版へ移る場合は保存先が異なるため、旧ZIPフォルダーを残してください。必要な履歴はアプリのバックアップ・復元操作で移し、鍵や履歴を削除しないでください。ZIP版を使い続ける場合は旧フォルダーを保管したまま、新版ZIPを展開してから更新方法を確認してください。

## Officeへ貼り付ける

［生成してPNGコピー］のあと、Word・Excel・PowerPointで `Ctrl+V` を押します。Excel・PowerPointでは形式を指定したPNG貼付も利用できます。Wordでは通常の貼付を使ってください。EMFやDIBを指定する操作は対応対象外です。

貼付後の印影サイズはOffice側で調整します。照合に使う予定の画像は、強い圧縮や極端な縮小を避けてください。表示日付は資料に表示する日付で、アプリが記録する実際の生成日時とは別です。

## 0.1.0から0.2.0への更新

0.2.0の通常印影は20bit形式です。旧12bit印影・原本・生成履歴は照合対象外で、自動変換はありません。プレーン形式は継続対応です。

1. 0.1.0で[バックアップ](BACKUP.md)を作り、アプリを閉じます。
2. 0.2.0のZIPを**新しいフォルダー**に展開します。
3. 0.2.0は新しい履歴保存先で使い始めます。
4. 旧履歴を参照する場合は、残しておいた0.1.0を使います。両版で同じ保存先を共有しないでください。

新版は旧ファイルや鍵を削除しません。バックアップを新版へ復元しても、旧12bit印影が照合可能になるわけではありません。旧版へ戻るときは、分けて残した旧版フォルダーを使ってください。新版で生成した履歴を旧版で扱えることは保証しません。

## 履歴を保管する

履歴と鍵は、基本的にEXEと同じフォルダーの`journal`と`key.dpapi`です。どちらも消したり書き換えたりしないでください。メニューで選んだ保存先は、その起動中だけ有効です。

別PCへの移行は、フォルダーをコピーするだけでは完了しません。[移行用バックアップ](BACKUP.md#別pcへの移行)を使ってください。

OneDriveのオンライン専用ファイル、複数PCから同じ履歴へ同時に書き込む運用、同期競合が起きているフォルダーは使用対象外です。

## 困ったとき

- **保存やコピーに失敗した**：空き容量と保存先の書き込み権限を確認します。「成功扱いにしていません」と表示された場合は、貼付できても記録が完了したとはみなさないでください。
- **鍵がない・履歴を読めない**：鍵を作り直したりファイルを削除したりせず、[バックアップからの復元](BACKUP.md)を確認してください。
- **旧印影を照合できない**：0.1.0の12bit形式か確認し、旧版で参照してください。

解決しない場合は[Issues](https://github.com/adachi6k/JTCStamper/issues)へ、バージョン情報・Windowsのバージョン・操作手順をお知らせください。
