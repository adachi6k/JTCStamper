# 履歴のバックアップと復元

アプリの［履歴］メニューから、生成した印影・日時・用途メモ・追記注釈をバックアップできます。

## どちらのバックアップを使うか

| 用途 | 選ぶ項目 | 必要なもの |
|---|---|---|
| 同じPC・同じWindowsユーザーでの復旧 | 同じWindowsユーザー用の履歴バックアップ（.jtcbackup） | 元のWindowsユーザー環境。パスフレーズ不要 |
| 別PCへ移る・Windows再インストールに備える | 別PCへの移行用バックアップ（.jtcportable） | 作成時に決めたパスフレーズ |

同じユーザー名でも、アカウントを作り直すと元の環境と同じにはなりません。PC交換や再インストールには移行用を使ってください。

## 同じWindowsユーザーで復元する

1. ［履歴］メニューで同じWindowsユーザー用のバックアップを保存します。
2. 復元するときは［同じWindowsユーザー用バックアップを復元…］でファイルを選びます。
3. 復元先となる新しいフォルダーを確認して実行します。
4. ［履歴 → 保存先を選択］で復元フォルダーを開きます。

既存の履歴へ上書き・結合はしません。バックアップ後に追加した記録は、そのバックアップからは戻りません。

## 別PCへの移行

1. 元のPCで［履歴 → 別PCへの移行用バックアップを保存…］を選びます。
2. 12文字以上の長く推測されにくいパスフレーズを設定し、ファイルを保存します。
3. 移行先のPCへファイルを渡し、［履歴 → 移行用バックアップから復元…］を選びます。
4. パスフレーズを入力して新しいフォルダーへ復元し、その保存先を開きます。

**パスフレーズを忘れると復元できません。リセット機能はありません。** パスワード管理ソフトなどへ保管してください。バックアップとパスフレーズを持つ人は履歴を取り出せるので、第三者へ渡さないでください。

元のPCやユーザー環境を失う前に移行用バックアップを作成してください。同じWindowsユーザー用バックアップの拡張子を変えても移行用にはなりません。

## 含まれないもの

文字などの設定ファイル（.jtcstamp）、外観設定、まだ保存していない用途メモや注釈は含みません。必要な設定は別に保存し、記録したい注釈は先に追記してください。バックアップの上限は256MiBです。

## 0.1.0の履歴について

バックアップは保存形式を変換しません。0.1.0の12bit記録を0.2.0へ復元しても照合対象にはなりません。旧版の参照用フォルダーを残してください。[更新手順](DISTRIBUTION.md#010から020への更新)

## 復元に失敗したら

元のフォルダーやバックアップを削除せず、パスフレーズ・空き容量・保存先の書き込み権限を確認してください。鍵ファイルを作り直しても、過去の履歴は復旧できません。同じWindowsユーザー用の場合は、元と同じWindows環境かも確認してください。

失敗後に`.jtc-restore-*`という一時フォルダーが残る場合があります。復元成功とは扱わず、元データをそのまま保全してください。正常な鍵や対応するバックアップがなければ、過去の履歴の認証は回復できません。

実装・暗号方式の詳細は開発者向けの[バックアップ技術資料](../developer/BACKUP-TECHNICAL.md)と[移行形式](../developer/PORTABLE-BACKUP.md)にまとめています。
