# 0.2.0 リリース準備

候補番号は0.2.0-rc.1。0.1.0からの新機能と12bit互換性削除があるため、0.1.1にはしない。正式公開・タグ作成はまだ行わない。

## 1.0.0の判断

公開可能であることと1.0の互換性契約は別。現在は20bit＋インクむらの製品描画の実機精度・誤受入評価が限定的であり、画像照合は試験機能のまま。今回は0.2.0候補でCIと配布検証を進める。1.0化にはVERSIONING.mdの公開インターフェース（履歴・原本・バックアップ・既存の照合機能）の互換性を維持できることを確認する。符号変更時に旧形式を保持する方針・試験を用意するか、今後の破壊的変更は2.0とする。1.0を真正性や無断コピー検知の保証とはしない。
