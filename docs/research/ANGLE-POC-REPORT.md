# JTCスタンパー：角度による符号化の基礎実験

## 結果

各セルは正しく4段階を復号できた件数/36試行。段階間隔1°は−1.5°、−0.5°、+0.5°、+1.5°。
相対角度の段階間隔2°は角度差−3°、−1°、+1°、+3°で、各横線の回転はその半分。

| 変換 | 全体角度・間隔1° | 相対角度・間隔1° | 相対角度・間隔2° |
|---|---:|---:|---:|
| PNG・88px | 36/36 | 36/36 | 36/36 |
| JPEG品質80・88px | 36/36 | 36/36 | 36/36 |
| PNG・66px | 36/36 | 36/36 | 36/36 |
| PNG・44px | 36/36 | 36/36 | 36/36 |
| PNG・全体を追加2°回転 | 9/36 | 36/36 | 36/36 |
| JPEG品質80・追加2°回転 | 9/36 | 21/36 | 36/36 |

全体角度は回転なしなら今回の全段階間隔で復号できた。後から回転すると値が変化し、
端の1符号へ寄るため9/36が残るが、回転耐性があることを意味しない。
相対角度は幾何学的には全体回転で不変だが、有限画素と固定読み取り窓の影響が残った。
0.5°間隔では追加回転PNGが33/36、追加回転JPEGが11/36。
1°間隔でも回転とJPEGの組合せで21/36となり、2°間隔では今回の全216試行で成功した。

したがって角度による2-bit搬送は有望。ただし、現時点の広めの候補は相対角度差の間隔2°。
成功率100%はこの1画像・既知領域・有限変換条件内の観測値であり、一般の信頼性を保証しない。
角度の見た目は比較画像で判断し、実装前に異なる氏名/日付/字体と実際のOffice経路を評価する。

## 対象と目的

ユーザー提供の `upload/01-image.png`（132×131px、印影の不透明範囲88×87px）を使用。
ダミー印影ではない。余白を取り除き、回転による欠けを避ける8pxの白余白を加えて測定した。
実験の目的は角度4段階による2-bitの読み分けであり、12-bitの容量や偽造検出能力の実証ではない。

## 方法

- 全体角度：円・氏名・日付・横線を一緒に回転する。
- 相対角度：上側横線を+角度/2、下側横線を−角度/2だけ回転する。文字は変更しない。
  元画像から横線の内部を抽出して加工し、外円との短い接合部は元のまま残す。
- 段階間隔0.5°、1°、2°。各間隔gに対して角度は−1.5g、−0.5g、+0.5g、+1.5g。
- 元画像を8倍に補間して変換し、印影幅88/66/44px相当へラスタライズする。
  元画像はラスターであり、補間は新しい文字細部を復元するものではない。EMF生成の代替実証ではない。
- PNG88、JPEG品質80（88px）、PNG66、PNG44、PNG88で全体を追加2°回転、JPEG80で追加2°回転。
- 各条件についてX/Yを−0.35、0、+0.35pxずらした9通り。4符号×9位置＝36件/条件。
- 計1,296件。決定的な変換試験であり、36件を独立した実運用の統計標本とはみなせない。

## 読み取り器

既知の印影切り出し範囲・横線位置を使う。各横線付近の赤色成分から列ごとの重心を求め、
重み付き直線回帰で傾きを推定。上下角度の平均を全体角度、差を相対角度とする。
無変調・88px・位置ずれなしの基準値を差し引き、4段階の最寄りへ分類する。
変換ごとの追加校正、正解角度の入力、ログによる補正は行わない。

この読み取り器はページ中の印影探索や任意位置・大角度の回転への対応を実装していない。
縦横独立の拡縮、スキャン、印刷、Office、EMF、PDFも未試験。
既知領域への依存と文字の混入による角度推定の偏りは今後の課題。

## 認証上の注意

最寄り分類だけでは透かしのない0°画像にも必ず何らかの符号を割り当てる。
`controls.json`に無変調の測定値を収録したが、真正/偽造の受入閾値は未設計であり、
この結果から偽造の誤受入率は求められない。
認証には判定不能領域、照合候補数、ログとの対応を含む別の評価が必要。

## ファイルと再現方法

- `trials.csv`：全試行の角度・誤差・復号結果
- `summary.csv`：条件ごとの成功数と最大絶対角度誤差
- `controls.json`：無変調画像の測定値
- `angle_comparison.png`：1°間隔の4段階。各セル上が原寸、下が1.5倍の最近傍拡大
- `input_crop.png`：入力印影の切り出し

ZIPを展開し、Pythonと Pillow / NumPy / SciPy を用意して `python angle_experiment.py` を実行。
結果は `angle_results` に出力される。入力原本もZIP内の `upload/01-image.png` に含む。

## 公開資料の範囲

個人の実物印影を含む元のPoC ZIP・画像は公開リポジトリに含めません。本文は観測結果のみを残したもので、現行アプリの精度を保証するものではありません。
