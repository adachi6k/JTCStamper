## 別PC移行（Issue #15）

Windows Server 2025（build26100）で作ったパスフレーズ付きバックアップを、別ジョブのWindows Server 2022（build20348）へ転送して復元した。マシン名とWindows SIDのハッシュがともに異なることを試験内で必須とした。復元先ユーザーのDPAPIで再保護した鍵を実際に開き直し、3印影・12記録・3注釈・保存画像ハッシュ・全署名済み記録・原本認証を確認した。

誤パスフレーズ、暗号文破損、既存復元先への上書きを拒否。Windowsで使用中の既存バックアップへの置換も拒否し全バイトを保持。Coreでは鍵すり替え、ヘッダー/nonce/暗号文/タグの改変、長さ不正、既存保存先の保全を検証。アプリ側でも鍵ファイルすり替えを拒否する。NTFS VHDの実容量不足（エラー112、空き0バイト）で移行用バックアップの上書きが既存ファイルを壊さないことと、容量回復後の保存・復元を確認。VHD切離し・削除も成功。

UIに同一Windowsユーザー用と別PC移行用のメニュー、確認入力付きのパスフレーズ欄、忘れた場合に復元できない説明を追加した。GUI自動操作ツールの環境エラーにより、パスフレーズダイアログの手動操作・Narrator等は未実施でIssue #13に残る。

CIの移行ファイルは架空の「CI TEST / TRANSFER」だけを使う。ジョブ間で合成暗号化ファイルと比較用ハッシュのみを転送し、保存期間は1日。試験パスフレーズは公開の実行識別子から導出する合成データ専用値であり、ユーザーの秘密ではない。個人の鍵・履歴を使わず、配布ZIPやこの検証成果物には合成バックアップ自体も含めない。暗号形式・パラメーター・制限は[PORTABLE-BACKUP.md](../../developer/PORTABLE-BACKUP.md)、使い方は[BACKUP.md](../../user/BACKUP.md)を参照。
