# 照合の独立入力評価計画（2026-09-26、実行前に固定）

対象は製品コード40dfe09のPNG/12-bit照合。過去のPoC・Pillow432条件・Windowsの復号スモーク画像は使わず、新しい16印面の管理された合成入力を作る。調整用データへ戻して閾値を変更せず、そのまま結果を報告する。これは外部機関の評価や印刷スキャンの自然画像ベンチマークではない。PowerPointの実際の保存・再読込・PNG書出しを独立した画像化経路として含める。

## 固定する設定と判定基準

- 製品の領域探索・赤色抽出・復号をそのまま使用。候補抽出の形0.72、文字0.3＋コード0.7、上位8画像、直近300画像、最大30領域を変更しない。
- 通常のコード絞込みを使用し、コードを読めない場合は全参照画像を比較する。
- 原PNG完全一致は、対応する履歴が存在する条件で全件Matchとなること。模倣画像のファイル完全一致Matchは0件を要求する。模倣画像の緑OKとは別の指標とする。
- 管理された無加工の製品PNG（384pxキャンバス）の幾何復号は95%以上を目標とする。96pxキャンバス（外円約88px）の文書画像は探索90%以上・正規復号90%以上を目標とする。これを下回る条件は、実験条件の失敗／未対応として明記し、一般的なロバスト性を主張しない。
- JPEG・回転・小サイズ・縦横比の変化・Office再画像化は条件ごとに分け、未達を平均に埋めない。80px未満の外円は現行復号の仕様外である。
- 緑OKの模倣率は必ず報告するが、緑OKを真正性の受入れ判定には使わない。0件であっても率0を証明しない。

## 新しい入力群

固定seed `JTC-heldout-20260926-v1`からイベントIDを生成する。16印面は架空の試験用氏名・文字と異なる日付を使用する。

1. 正規群：原PNG、文書中96/72/48pxキャンバス、96px JPEG品質85、追加回転+3°、薄灰背景、横方向1.1倍、およびPowerPoint保存・再読込後の96px相当PNG書出し。
2. 紛らわしい履歴：同じ上段・下段で日付が1日違うもの、同じ文字・別イベント／別コード、同じ印面・同じコードへ意図的に衝突させた別イベント、別の下段を含む。衝突でPNG自体が同じになる場合も複数一致として残す。
3. 模倣群：独立した描画関数で円・水平線・文字を配置する通常模倣と、公開方式に従って同じ幾何コードと線角度を描く模倣。生成元PNGの画素は使わない。
4. 無断コピー群：正規PNGそのものと、正規PNGを再保存した画像。対象外として別集計し、模倣の誤受入分母に混ぜない。
5. 履歴件数は0／32／1,000件。古い参照画像が直近300画像から外れるケースも別記する。

## 集計

画像と生成元のID・ハッシュ、変換条件をmanifestに保持する。正規群について、領域検出率、正しい符号／誤符号／未読取、正しいイベントの候補包含、最上位の正答／誤対応／同点／候補なしを別集計する。完全一致の複数記録と画像候補の同点は一意の正答と扱わない。各分母は全対象入力で、判定不能を除かない。

同じ原画像からの変換結果は独立試行とみなさず、条件別の16原画像を単位とする。二項比率のWilson区間を参考値として併記し、人工的に構成した小標本なので実世界の出現率を推定するものではないと説明する。緑OK模倣率とPNG完全一致の誤受入率は別に示す。

正規PNGの幾何復号は研究指標として併記するが、実際のアプリではファイル完全一致なら幾何探索を行わない。評価ハーネスはこの区別を記録する。

原本・鍵はこの評価では合成専用。個人の履歴やPoC印影は使わない。Office試験は自分で作成した文書だけを保存・終了し、既存の文書やクリップボードは変更しない。
