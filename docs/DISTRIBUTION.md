# 配布版・更新・既知の制限

現在は未リリースのプレビュー準備段階です。初版はWindows 11 x64・PNGのプレビューとし、照合は試験機能です。提供範囲はdocs/RELEASE-SCOPE.md、配布可否はIssue #1で管理します。

| 版 | .NETの同梱 | 必要な環境 |
|---|---|---|
| 通常版（推奨） | あり | Windows x64 |
| 軽量版 | なし | Windows x64、.NET 10 Desktop Runtime x64 |

Windows 11 x64を主な検証対象とし、Windows 10・ARM64は対応済みとは扱いません。サイズはビルドにより変わるため、同梱build.jsonと配布checksums.jsonを参照してください。機能と保存形式は両版共通です。

## 起動

ZIPを専用の書込み可能なフォルダーへ展開し、JTCStamper.App.exeを起動してください。start.cmdも管理者権限も不要です。ZIP内からの直接実行は避けてください。EXEは短いパスへ置いてください（例: C:\Apps\JTCStamper）。260文字を超えるEXEパスは実機で起動失敗しており、対応範囲外です。長い保存先への読書きと、WindowsがEXEを起動できるかは別の制限です。

起動後は履歴の準備状況を画面下部に表示します。生成・保存処理中もウィンドウの移動や画面切替はできますが、二重コピーや保存先変更はできません。処理中に閉じると完了後に終了し、保存に失敗した場合は閉じずに結果を表示します。

軽量版は[Microsoft公式](https://dotnet.microsoft.com/en-us/download/dotnet/10.0)の「.NET Desktop Runtime」Windows x64を使います。「.NET Runtime」だけではWPFに不足します。SDKは利用者には不要です。未導入環境の案内は受入試験で確認します。

通常版は起動時に同梱ライブラリを一時領域へ展開するため、TEMPの容量と書込み権限が必要です。OneDriveのオンラインのみのファイルは先にダウンロードし、同期競合時の使用は避けてください。これらの失敗条件は試験対象で、動作保証済みではありません。

## 保存と更新

1.0.0未満では後方互換性を保証せず、旧印影の照合や旧保存形式の読込を廃止する場合があります。互換対応・移行ツールの提供は必須としません。更新前に変更履歴で対象形式と移行の有無を確認してください。以下のEXE差替えは同じ保存形式を使う場合の手順です。旧形式を非対応にしても、既存データを黙って削除・上書きはしません。

EXEの隣のjournalとkey.dpapiが履歴と鍵です。設定ファイル(.jtcstamp)とappearance.jsonも個人データとして扱います。保存先選択は今回の起動中だけ有効です。

アプリを終了して同じフォルダーのEXEだけを交換します。通常版と軽量版も同様です。フォルダー全体を配布ZIPで置き換えたり、鍵・履歴を削除したりしないでください。更新前に同じユーザー環境で鍵と履歴の一式を保全してください。［履歴］メニューのバックアップ／復元は、同じWindowsユーザープロファイルとDPAPI環境専用です。鍵・履歴・保存画像・追記済み注釈を保護し、新規フォルダーへ復元します。設定ファイルと未追記注釈は含みません。別PCやWindows再インストールに備えるには、元環境で［別PCへの移行用バックアップを保存…］から.jtcportableを事前に作成してください。パスフレーズを忘れると復元できません。移行先の［移行用バックアップから復元…］で新しいフォルダーへ復元します。スキーマ移行は未対応です。詳しくはリポジトリのdocs/BACKUP.mdを参照してください。

更新に失敗した場合はアプリを閉じて以前のEXEへ戻し、データをそのまま残します。異なるスキーマへ変更するリリースでは、旧版への復帰可否を別途検証して案内します。既存データを修復のために勝手に消したり、鍵を再作成したりしないでください。

履歴は生成順で表示します。表示日付と実生成時刻は別物です。注釈は追記、全削除は［履歴］メニューから対象件数・保存先を確認後に実行します。HMACは暗号化ではなく、末尾削除・巻戻しの完全検知も保証しません。

## 機能と照合

［印影を作成］［印影を照合］［生成履歴］をサイドバーで切り替えます。上段・下段・プレーン設定を保存でき、日付は通常当日、例外時だけ指定します。作成画面にも直近3件と画像を表示します。［表示 → テーマ］でライト・ダーク・Windows連動を選べます。

PNGコピーに対応し、EMFは未対応です。通常印影は12-bitコード、プレーンは幾何情報なしです。生成時のPNGを履歴に保存し、古い記録の再現画像とは区別します。

画像照合は試験機能です。元PNGの完全一致、原本認証、加工画像の候補を分けて表示します。候補スコアは文字・日付が最大0.3、コード一致が0.7。1.000は文字の形とコードが履歴候補と一致した点数で、画像全体の一致とは別です。候補の目視確認が必要です。［一致記録なし］は偽造を意味せず、正規画像の無断コピーは検出対象外です。

比較対象は直近300種類の保存画像、検出30領域、上位8画像。新しい16印面とPowerPoint書出しで条件別に評価しましたが、小さい画像では日付違いの候補が最上位になる例もあります。候補の文字と日付を確認してください。任意画像・印刷スキャン全般の精度保証ではありません。結果と限界はdocs/HELDOUT-EVALUATION-2026-09-26.mdを参照してください。40セル冗長化は未搭載です。

## ビルド・成果物・試験

コミット済みのソースで scripts/New-ReleasePackages.ps1 を実行すると、通常版・軽量版のReleaseビルドと版番号付きZIPを生成します。ZIPはEXE・README.txt・build.json・LICENSE・NOTICE・THIRD-PARTY-NOTICES.txtを収録し、鍵や履歴は収録しません。dist/packages/checksums.jsonにZIPとEXEのハッシュ、版番号、ソースコミットを記録します。バイト単位の再現ビルドを保証するものではありません。

GitHub ActionsはCoreチェックとWindowsスモークを実行します。実Office貼付、実クリップボード、DPI・Narrator操作、.NET未導入環境は別の受入試験です。CI成功だけで実機確認済みとは扱いません。

ソースはApache-2.0、依存物はそれぞれのライセンスに従います。配布ZIPにはLICENSE・NOTICE・THIRD-PARTY-NOTICES.txtを同梱します。ライセンス・公開画像・配布方針のレビューはIssue #9、最終公開判断はIssue #1に記録します。公開済み0.1.0のEXEは未署名です。自己署名を使用する配布ではbuild.jsonのSigningを確認してください。自己署名はSmartScreen警告の解消を保証しません。詳細は[コード署名](CODE-SIGNING.md)を参照してください。Standard版preview.11の実ダウンロード確認では、初回に発行元不明の警告が観測され、その後の操作は成功しました。警告の種類は未特定で、全環境の起動可否を保証しません。

不具合報告には［ヘルプ → バージョン情報］の内容、OS、再現手順を添えてください。秘密鍵や個人履歴一式の提出は不要です。

初回プレビューは未署名ZIPをGitHub Releasesで配布する方針です。組織管理PCや署名必須・アプリ実行禁止の保護設定のある環境は対応範囲外です。保護設定の無効化は案内しません。

## Office貼付の確認済み経路

preview.12の通常版/Liteとも、Wordの通常貼付、ExcelとPowerPointの通常貼付・PNG形式指定貼付で保存再読込と透明度/寸法/画素保持を確認しました。Wordでは通常貼付を使用してください。DIB（デバイスに依存しないビットマップ）指定は通常版の試験で「指定した種類のデータは使用できません」となり、初版の対応範囲外です。すべての貼付形式への変換には対応していません。詳細はdocs/OFFICE-ACCEPTANCE-PREVIEW12-2026-09-26.mdを参照してください。

初回プレビューの履歴保存先はローカルの書き込み可能なフォルダーを対象とします。OneDriveのオンライン専用ファイル、同期中の履歴への競合書込み、複数PCで同じ履歴を同時に開く運用は対象外です。実同期競合を試験済みとは扱いません。

物理スリープ復帰の実機試験は初回プレビューでは省略しています。復帰後の不具合があれば、OSと再現手順を添えて報告してください。
