# 初回プレビューの範囲

2026-09-25にIssue #10の判断として確定。公開許可ではなく、試験対象と案内する機能の範囲を固定する。

- 初版は0.1.0-preview系列のプレビュー。正式版ではない。
- 対象はWindows 11 x64。Windows 10、ARM64は未検証・対応保証外。
- 通常版（.NET同梱）と軽量版（.NET 10 Desktop Runtime x64が必要）を同一コミットから提供。
- 上段・下段・当日／指定日、通常／プレーン、PNGコピー、印面設定、生成履歴・生成画像・追記注釈・原本保存を対象とする。
- 履歴と鍵のバックアップは同じWindowsユーザープロファイルのDPAPI環境用。別PC移行はIssue #15で継続。重要な証跡の唯一の保管先にしない。
- 画像照合は試験機能。12-bitは候補検索補助であり、認証でも偽造判定でもない。緑OKは真正性を証明しない。独立実画像評価と説明の理解度確認はIssue #4で継続。
- 40セル誤り訂正案は研究のみ。現行製品の冗長化性能として告知しない。
- EMFは初回プレビューに含めない。元の要件として維持し、Office経路のIssue #5で実装・検証を継続追跡する。
- 自動ファイル関連付けとコマンドラインでのファイル読込は提供しない。アプリ内のメニューで開く。

## 配布前のゲート

保存失敗をコピー成功と扱わないこと、鍵・履歴の破損を黙って修復しないこと、対象EXEの起動・再起動・更新、最終ZIPの内容・ハッシュ・ライセンスを確認する。未実施の実機チェックを成功へ読み替えない。

DPI・キーボード等のGUI確認はIssue #13、実環境の貼付は#5、性能は#8、全体レビューは#2に記録する。後続機能を除外しただけではこれらのIssueは閉じない。

Privateを維持し、Git履歴から除いた実物印影のGitHub側キャッシュも含む公開前確認（#9）と、親Issue #1の公開判断が終わるまでPublic化しない。
