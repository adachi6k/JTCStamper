# JTC Stamper

**日付印を作って貼る。作った記録も残す。**

氏名や部署名を入れた日付印を、Word・Excel・PowerPointへ貼り付けられるWindowsアプリです。作成した印影は履歴に残り、あとから用途のメモを追加できます。アカウント登録や中央サーバーは不要です。

**[ダウンロード](https://github.com/adachi6k/JTCStamper/releases)** · [使い始める](#使い始める) · [変更履歴](CHANGELOG.md)

![印影を作成する画面。文字と当日の日付を確認し、青い「生成してPNGコピー」ボタンでコピーできます。](docs/images/create-light.png)

*画面の表示内容はサンプルです。*

## できること

- **自分の日付印を作る** — 上段・下段の文字を自由に設定。日付は通常「今日」、必要なときだけ過去や未来の日付を指定できます。
- **資料に貼り付ける** — ボタンで印影をコピーし、貼付先で `Ctrl+V`。背景が透明なPNGなので、資料の上に重ねられます。
- **作った印影を振り返る** — 作成画面に直近の履歴を表示。「生成履歴」では保存画像を見ながら、用途や貼付先などをメモできます。
- **画像から履歴を探す** — 手元の画像を読み込み、自分のPCに保存した生成履歴と照合できます。照合は改善中の試験機能です。

よく使う文字の設定はファイルへ保存できます。ライト・ダーク・Windows連動のテーマにも対応しています。

## 使い始める

対応環境は **Windows 11（x64）** です。次の3ステップで使い始められます。

1. **通常版をダウンロード**

   [配布ページ](https://github.com/adachi6k/JTCStamper/releases)の「Assets」から、名前に **`Standard`** が付いたZIPを選びます。通常版には実行に必要なものが含まれています。
2. **ZIPを展開して起動**

   書き込み可能なローカルフォルダーへ展開し、`JTCStamper.App.exe`を起動します。インストーラーや`start.cmd`は不要です。
3. **文字を入れてコピー**

   「印影を作成」で上段・下段の文字を入れ、日付を確認して **［生成してPNGコピー］**。WordやExcelなどへ切り替え、`Ctrl+V`で貼り付けます。

迷ったら通常版を選んでください。すでに .NET 10 Desktop Runtime（x64）を導入している方には、小さい **Lite版** も用意しています。詳しい起動・更新方法は[配布ガイド](docs/DISTRIBUTION.md)へ。

> 現在のEXEは未署名のため、初回起動時に発行元不明の警告が出ることがあります。

## 履歴を残して、あとからメモ

「生成履歴」で印影を選ぶと、作成時の画像や日時を確認できます。用途や貼付先は、あとから注釈として追記できます。

記録するのは**生成・コピー**です。貼付先への貼り付け完了を自動で確認する機能ではありません。

履歴は基本的にアプリと同じフォルダーへ保存します。履歴を残したい場合は、アプリのフォルダーごと削除しないでください。PCを変える前には、［履歴］メニューから移行用バックアップを作成してください。[バックアップの手順](docs/BACKUP.md)

## 画像照合について

「印影を照合」で画像ファイルやクリップボードの画像を読み込み、履歴の候補を探せます。

**1.000は履歴候補との比較点数で、画像全体の一致とは別です。保存画像をそのままコピーしたものは見分けられません。** 画像の状態によって読めない場合もあり、一致する履歴がなくても偽造とは断定できません。[照合の使い方](docs/VERIFICATION.md)

## 更新・サポート

1.0.0までは、印影の符号方式や保存形式が変わり、旧データに対応しなくなる場合があります。更新前に[変更履歴](CHANGELOG.md)を確認してください。

不具合や使いにくい点は[Issues](https://github.com/adachi6k/JTCStamper/issues)へ。［ヘルプ → バージョン情報］の内容と、操作手順を添えると調査しやすくなります。画像を添付する場合は、架空の文字で作ったサンプルを使ってください。個人の印影・履歴・秘密鍵の添付は不要です。
