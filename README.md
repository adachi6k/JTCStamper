# JTC Stamper — Just To Confirm

**確認した、その記録を。** Windows向けの日付印アプリ。C# / .NET 10 / WPF。

現在はリリース準備中です。[残作業と受入条件](https://github.com/adachi6k/JTCStamper/issues/1)、[リリース前レビュー](https://github.com/adachi6k/JTCStamper/issues/2)で進捗を管理しています。Public化は試験と公開前確認の完了後に判断します。

バージョンは[SemVer 2.0.0](https://semver.org/spec/v2.0.0.html)に従います。互換性の対象と0.x・プレビューの運用は[バージョン規約](docs/VERSIONING.md)を参照してください。 **1.0.0までは後方互換性を保証せず、幾何符号や保存形式、旧形式対応を変更する場合があります。** 対象と移行の有無は変更履歴で案内します。

## 主な機能

- 上段文字・表示日付・下段文字を持つ赤い印影。日付は通常当日で、［日付を指定］で過去・未来も選べます。表示例は `'26.09.25`。
- 通常形式（12-bit幾何コード）と、幾何情報を埋め込まないプレーン形式。
- PNGのクリップボード出力（Bitmapも登録）。EMFは未対応です。
- 固有イベントID、実生成UTCと表示日付を別々に記録。生成画像もHMACで保護した記録に保存します。
- 生成・コピー要求・コピー結果の履歴、上書きしない注釈追記、認証情報付き原本 `.jtc` の保存。
- 生成画像の表示、直近3件の履歴、保存済み生成履歴の全削除（メニューから確認後に実行）。
- 画像内の印影探索と履歴候補の照合（試験機能）。原本認証、PNGファイル全体の完全一致も確認できます。
- 折りたたみサイドバー［印影を作成］［印影を照合］［生成履歴］、ライト・ダーク・システム連動。

コピーの記録は貼付完了を意味しません。生成記録やコピー完了記録の保存に失敗した場合、コピー成功と表示しません。

## 起動とビルド

通常版は.NETを同梱、軽量版は.NET 10 Desktop Runtime x64が必要です。配布ZIPを専用の書込み可能なフォルダーへ展開し、`JTCStamper.App.exe`を起動します。バイナリはGitに含めていません。

開発には`global.json`で指定する.NET SDKとWindows環境が必要です。

```powershell
dotnet run --project src/JTCStamper.App -c Release
# 両版のEXEを生成
.\publish-all.cmd
# コミット済みソースから版番号付きZIP・ハッシュを生成
pwsh -File .\scripts\New-ReleasePackages.ps1
```

EXEは`dist/win-x64`と`dist/lite-win-x64`、ZIPと`checksums.json`は`dist/packages`へ出力します。［ヘルプ → バージョン情報］で版番号、コミット、配布形式を確認できます。正確なサイズは各ビルドの`checksums.json`を参照してください。

## 保存先と設定

既定ではEXEの隣の`journal`と`key.dpapi`へ保存します。［履歴 → 保存先を選択］で変更できますが、選択はその起動中のみです。上段・下段・プレーン設定は［ファイル］から`.jtcstamp`へ保存・読込できます。読込後の日付は当日に戻ります。テーマ設定は`appearance.json`へ保存します。

鍵を失うと既存履歴を検証できません。DPAPI CurrentUserの鍵は同じWindowsユーザーの保護に依存し、別PCへファイルをコピーするだけでは移行できません。［履歴］メニューから同じWindowsユーザー用の暗号化バックアップと新しいフォルダーへの復元ができます。別PC移行には、元環境を失う前にパスフレーズ付き移行用バックアップ（.jtcportable）を作成してください。復元先で鍵を保護し直します。[バックアップの範囲と手順](docs/BACKUP.md)を確認してください。

HMACは改変の検出に用いる認証情報で、履歴の暗号化ではありません。生成画像・注釈を含む記録はファイルへアクセスできる人が閲覧できます。末尾の削除や過去のバックアップへの巻戻しを完全検知する仕組みでもありません。

## 照合の読み方と限界

通常形式の12-bitコードは4096通りで、画像から履歴候補を探す補助情報です。完全なイベントIDとHMACは原本とローカル記録に保持し、画像コードによる真正性の証明はしません。

画像の候補は文字・日付の一致に最大0.3、読めたコードの一致に0.7を加える暫定スコアです。1.000の緑OKも候補としての対応スコア最大を意味し、真正性の証明ではありません。プレーンはコード加点なしです。候補抽出には別の形比較閾値0.72を使用します。

元PNGのファイル全体の完全一致、原本の認証、加工画像の候補は区別します。［一致記録なし］だけで偽造とは断定しません。他人が模倣して作った画像の照合補助が目的で、正規画像の無断コピーは自動検出の対象外です。

画像候補は直近300種類の保存画像（同じ印面でもPNGが異なれば別対象）、検出領域30件、上位8画像までです。照合画面の説明で比較範囲を確認してください。PNG・JPEG・BMP・単一ページTIFFに対応し、コードを読めない画像もあります。

Windows 11 x64を主な検証対象としています。Windows 10・ARM64の対応保証、実Office・スキャン画像の精度評価、EMF、原本の履歴取込は未完了です。40セルの冗長化案は研究のみで、現行製品の性能には含めません。
